# homepage
This my own homepage

页面的内容都写在 `index.html` 的 HTML 里：去过的城市、还没来得及写的地方、写过的项目，各是列表里的一个 `<li>`，怎么加地方写在那段注释里。

浏览器支持 WebGL、窗口也放得下的话，会在这份 HTML 上面画一张桌子：字印在桌面上，每个写过的城市是一颗玻璃弹珠。桌子上的东西都是从 HTML 里读的，改页面就行，不用动脚本。不支持、放不下、画得太慢，或者点了桌子右下角的「文字版」，看到的就是原来的页面（页脚的「弹珠版」可以回到桌子）。

`travel.html` 只是跳到首页的 `#places`。
